# D3.1 — comparación visual antes/después

D3 permanece como una sola base. D3.1 responde punto por punto a la evaluación visual del comentario [#6368468984](https://github.com/sjo1848/alquileres-uspa-cloudflare/issues/41#issuecomment-6368468984); no presenta otra dirección.

## Cambios visibles

| Área | Antes · D3 | Después · D3.1 |
|---|---|---|
| Identidad y catálogo | Logotipo geométrico genérico, sans uniforme y una foto repetida en dos cards. | Marca de cordillera con palabra “Uspallata”, serif editorial local + sans operativa, paleta mineral/verde cordillera/arcilla y tres fotos locales diferentes. La búsqueda sigue antes del catálogo. |
| Texto y cards mobile | Datos compactos y precio/estado en columnas que podían partir el importe. | Cuerpo 14–16 px; precio tiene línea propia; búsqueda usa “Uspallata, Mendoza” completa y no se recorta. Estados y periodicidad siguen junto al alojamiento. |
| OWNER | Resumen de propiedades, sin recorrido de edición/fotos evaluable. | Editor con secciones Información/Fotografías, galería ordenable ilustrativa, selección local, previsualización pendiente y CTAs distintos para guardar foto, guardar publicación y enviar a revisión. |
| ADMIN mobile | Cola y detalle apilados: para hallar el caso había que pasar primero por toda la lista. | Lista primero; seleccionar un caso abre el detalle; volver devuelve el foco a la fila seleccionada. Desktop conserva lista + panel contextual. |
| Gestión asistida | Formulario largo y conjunto de acciones simultáneas. | Tres secciones plegables (datos, disponibilidad, revisión) y CTA de guardado persistente/visible; solo una sección se mantiene abierta durante la interacción. |
| Capturas mobile | El reporte anterior aplicó una regla CSS que quitó la posición fija de navegación. | Capturas viewport reales con navegación inferior fija y barra de acciones asistidas fija. Solo se oculta el selector del prototipo. |

## Sistema visual

- Fondo papel mineral `#f5f2eb`, superficie `#fffefa`, tinta `#202a2d`, verde cordillera `#315f61`, arcilla `#ad573d`.
- Titulares editoriales Georgia local; interfaz sans del sistema. No se descargan fuentes.
- Marca vectorial inline de cordillera con línea de tierra; la geometría se usa en el wordmark, sin derivar una marca para ADMIN.
- Fotografías WebP locales, sintéticas y sin hosts remotos. La nueva escena de casa de adobe/piedra diferencia la tercera tarjeta; assets entre 172–457 KB.

## Límite de la comparación

D3.1 es un prototipo de diseño/flujo, no el runtime Vue + Worker. No prueba API, permisos, persistencia, envío, auditoría ni Product Acceptance. La muestra de fotografía seleccionada usa un archivo local sintético; no carga datos ni sube al producto. HUMAN_GATE sigue abierto.
